BRIGHTLOOP - SUBSCRIPTION MANAGEMENT SYSTEM


​ABOUT THE PROJECT
Brightloop is a web application created to handle customer subscriptions and recurring payments in one place. It helps businesses manage the entire customer journey from signing up to billing, sending invoices, collecting payments, and tracking revenue growth.
​THE PROBLEMS IT SOLVES
Before this system, subscription details were managed by hand:
​Customer records were scattered across offline spreadsheets.
​Renewals were easily forgotten, causing lost customers and missed income.
​Invoices had to be typed out manually every single month.
​Incoming payments were checked one by one against bank statements.
​Business owners could not easily see their real monthly recurring revenue.
​Brightloop solves these problems by automating billing dates, organizing invoices, and displaying revenue numbers clearly in real time.
​
KEY FEATURES
​Revenue Overview: Shows monthly recurring revenue, active customer count, total payments collected, and overdue payments across 7-day, 30-day, 90-day, and 12-month periods.
​Subscription Tracking: Handles daily, weekly, monthly, and yearly cycles. Automatically calculates next billing dates and tracks active, trial, overdue, and cancelled accounts.
​Invoices and Payments: Keeps track of generated invoices and payment methods such as cards, UPI, and bank transfers.
​
Three Access Levels:
​Admin: Can create plans, edit prices, invite staff members, and change company settings.
​Developer: Can view API keys, test webhooks, and see integration code samples.
​Standard User: Can view and search records for daily work without changing core settings.
​Excel and CSV Tools: Lets teams import and export their team member lists and subscription records using regular spreadsheet files.
​Discount Management: Allows admins to turn coupon codes and discounts on or off with set usage limits.
​Clean Interface: Includes both light and dark screen modes for comfortable reading.
​
PROJECT FILES
​index.html: The main website layout that connects to the database.
​style.css: The visual design and colors for light and dark themes.
​script.js: The background logic for calculating totals, filtering tables, and saving records.
​supabase-config.js: Holds the connection details for the online database.
​supabase-schema.sql: Sets up the database tables and user security rules.
​SUPABASE-SETUP.md: Written instructions for setting up the database.
​
HOW TO OPEN AND RUN
​Quick Demo: Open "index.html" in any normal web browser like Chrome, Edge, or Safari. The system will open right away with sample data.
​With Live Database: Set up a free Supabase project, run the "supabase-schema.sql" file in its editor, paste your project link into "supabase-config.js", and refresh "index.html".
